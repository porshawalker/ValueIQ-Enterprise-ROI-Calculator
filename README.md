# 📊 ValueIQ | Enterprise ROI & Business Case Engine

ValueIQ is an interactive business case and value realization calculator designed for Enterprise Account Executives and Business Value Consultants. It translates technical value propositions into quantifiable financial metrics, risk-adjusted payback timelines, and board-ready executive summaries.

---

### 🚀 Key Features
* **Dynamic Benchmarking:** Instant preset profiles for Mid-Market Sales Ops and Enterprise Support deployments.
* **Risk-Sensitivity Analysis:** Multi-scenario modeling comparing Conservative (50%), Target, and High-Adoption (90%) realization rates.
* **Payback Timeline Engine:** Visualized cumulative monthly net value realization tracking break-even points over 1-Year or 3-Year contract horizons.
* **Executive Brief Export:** One-click automated PDF report generation (via FPDF) for board meetings and deal champions.

---

### 🛠️ Tech Stack
* **Language:** Python 3.10+
* **Framework:** Streamlit
* **Data Processing:** Pandas
* **Document Generation:** FPDF2
